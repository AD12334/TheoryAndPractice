# PR Sample Size Consideration

## Context

The analysis used a sample of 80 individual pull requests (PRs). A sample of
this size carries a risk of undersampling: the observed results may not fully
reflect patterns across the available data or align closely with the findings
reported in the original paper.

## Options considered

We considered increasing the sample to around 100 PRs. Although this could
reduce some undersampling risk and make the findings more comparable with the
paper, the project has only about 250 available samples. Expanding the analysis
substantially could move the work toward reproducing the original study, which
the project brief cautioned against.

## Decision and limitation

We retained the 80-PR sample to keep the project scoped as an analysis rather
than a reproduction. The results should therefore be interpreted as findings
from a limited sample, not as a definitive representation of the full set of
PRs or a direct replication of the paper. The sample-size constraint is a
limitation and should be considered when comparing our findings with the
paper's results.
